Sale Returns

When goods come back — damaged, excess, wrong delivery or expired — Bizom tracks it as a return against the original invoice, at the primary or secondary level.

Primary Sale Return — overview

When a distributor returns goods back to the company or depot — because of damage, excess stock, a wrong delivery, or expiry — that transaction is a Primary Sale Return.

CharacteristicDetail
DirectionDistributor → Company / Depot
AgainstA previously created Primary Sale / Invoice
Inventory ImpactStock is added back to the warehouse/depot
Financial ImpactA credit note is issued to the distributor
TriggerDamaged goods, expiry, wrong SKU, excess stock, etc.

URL: /salemansalesreturns/salereturns/primarysalereturn

NotePrimary Sale Return is managed within the DMS module — a primary invoice must exist before a return against it can be initiated.

How it differs from Secondary Sale Return

Primary Sale ReturnSecondary Sale Return
FlowDistributor → CompanyRetailer/Outlet → Distributor
AgainstPrimary InvoiceSecondary Invoice
Managed inDMS (Distributor Management System)OMS / Field Sales App

URL for Secondary Sale Return: /salemansalesreturns/salereturns/

TipPrerequisites like platform workflow, app tab access, and return reasons need to be configured before this feature is available to users.
