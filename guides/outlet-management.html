Outlet Management

Add new outlets and edit existing ones through the app, the web dashboard, or in bulk with an MDM upload, plus how to customise the Add Outlet form for your own fields.

1. Customise the Add Outlet form

The Add Outlet / Edit Outlet screen is fully customisable, even fields in the standard outlets table can be renamed, reordered, made mandatory, or hidden. This is controlled from the Basic Outlet Form.

From this form you can:

  • Rename existing fields
  • Add basic outlet fields that aren't configured yet
  • Remove fields you don't need
  • Change the order fields appear in
  • Add input validation for any field
  • Make a field mandatory, editable, or read-only

  1. Log in to the Bizom web portal

    Use your admin credentials.

  2. Go to Account → Settings

  3. Open the Form Settings tab

  4. Click Basic Outlet Form

    This opens the field configuration screen shown below.

FieldWhat it does
Outlet ColumnsDropdown of extra columns available to add to the Add Outlet screen. Use Add Column to bring one in.

2. Add an outlet via the app

Field reps can add a new outlet directly from the app while out on a beat, useful for on-the-spot additions without waiting for a web/MDM update.

  1. Open the beat and tap the add-outlet icon

    From the outlet list for today's beat, tap the icon in the top-right corner.

  2. Enter the outlet name and owner's mobile number

    Bizom uses these two fields to check for duplicates before creating anything.

  3. Confirm there's no duplicate

    Bizom searches nearby outlets by name and number before letting you continue.

  4. Fill in the rest of the outlet's details

    Name and mobile number carry over automatically. Address and Contact Person Name are required; the rest of the standard fields follow below.

3. Rename existing fields

You can relabel any field on the Add Outlet / Edit Outlet screen without touching the underlying data.

  1. Open the Basic Outlet Form

  2. Update the Column Alias

    For example, changing "Address" to "Outlet Address".

  3. Click Update

    You'll see "Basic Outlet Form is Updated". The new label now appears wherever the field is shown.

4. Add outlets in bulk via MDM

For onboarding many outlets at once, use the Outlets MDM upload instead of adding them one by one on the web.

  1. Go to your MDM listing

    Navigate to yourcompanyurl.bizom.in/mdms

  2. Search for "Outlets MDM upload"

  3. Download the template and fill in the mandatory fields

  4. Upload the filled file and review the validation results

Sample fileAlways start from the downloaded template rather than building your own, required column names are specific to your Bizom instance.

Mandatory fields for the Outlets MDM
FieldNotes
nameOutlet name, max 255 characters.

city_id & nameMust exist in the Cities table and belong to the correct district.
district_id & nameMust exist in Districts and belong to the correct state.
state_id & nameMust exist in the States table.
outlet_typee.g. Grocery, Departmental Store, Modern Trade, Pharmacy, etc.

phonenoMust be a valid phone number.

erp_idOptional, only needed if you integrate with an external ERP.

This is the essential subset, the full template has 100+ optional columns (GST, banking, KYC, credit terms, etc.) for advanced use cases. Ask support for the complete field reference if you need one of those.

5. Updating outlets via MDM

The same MDM area supports bulk updates to outlets you've already created, useful for correcting addresses, re-mapping areas, changing outlet status, or fixing contact details at scale.

  1. Go to yourcompanyurl.bizom.in/mdms and open "Update Outlets"

  2. Include the outlet's id

    This is mandatory for an update, it's how Bizom knows which record to change. Only the columns you fill in get updated; leave the rest blank.

  3. Upload and confirm

    Errors are shown row-by-row so you can fix and re-upload just the failed rows.

NoteSome fields (like an outlet's warehouse mapping) can't be changed through this update MDM. Reassignment flows (like appendareaID / removeareaID) exist for specific cases; contact support if you're not sure which applies to you.
