Beat Creation & Assigning

A beat is the route a salesperson follows, the outlets they visit, in order, on a given day. Set these up correctly and your team's daily journey plans build themselves.

3 min read
Web & MDM
Beginner friendly
On this page
  1. Create a beat
  2. Beat MDM templates
  3. Which template should you use?
  4. Assigning beats to users

1. Create a beat

  1. Open the Add Beat form

    Go to yourcompanyurl.bizom.in/beats/add

  2. Fill in the details

    FieldWhat to enter
    Beat NameName of the beat you want to create.
    AreaThe area this beat belongs to.
    ERP IDOptional, only if your system uses ERP integration.

  3. Submit the form to save the new beat

2. Beat MDM templates

Two MDM templates cover beat management:

TemplatePurpose
BeatsUpload and update beats in bulk.
Beat Area MappingMap beats to areas.
Beats MDM Template.XLS · Ready to fill and upload

3. Which template should you use?

You want to…Use this MDM
Add new beats in bulkBeats
Map beats to areasBeat Area Mapping

TipSet up your areas before your beats, a beat always maps to an area, so creating them in that order avoids rework.

4. Assigning beats to users

Creating a beat is only half the job, it needs outlets mapped to it, and a salesperson assigned to cover it.

  1. Create the beat via MDM

    Use the Beats MDM template (see above) if you haven't already.

  2. Map outlets to the beat

    Use the Map outlets to beats MDM. You only need to enter the Outlet ID and Beat ID to map them.

  3. Assign the beat to a user

    Once outlets are mapped, assign the beat to the salesperson who'll cover it from the PJP screen, this is also where you set which days of the week they visit it.
