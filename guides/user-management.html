User Creation & Update

A user is anyone who accesses Bizom, field sales reps, managers, distributors, admins. Each one needs a role, a designation, and a place in the hierarchy.

5 min read
Web & MDM
Admin access needed
On this page
  1. Create a new user
  2. How a user fits in the hierarchy
  3. Bulk upload via MDM

Before you startYou'll need admin access, and the Role, Designation and Warehouse this user maps to must already exist, plus you should know who they report to.

1. Create a new user

  1. Go to Admin Panel → Masters → Users → Add User

  2. Fill in basic details

    FieldWhat it meansRequired
    First / Last NameThe user's name✅ Yes
    Mobile NumberPrimary contact and login ID✅ Yes
    Email IDThe user's email address✅ Yes
    Employee CodeERP / HR employee codeOptional
    Date of JoiningJoining dateOptional

  3. Assign Role & Designation

    FieldWhat it means
    RoleSystem role, e.g. Salesman, Zone Manager
    DesignationJob title, e.g. TSI, ASM, RSM

  4. Map to the hierarchy

    FieldWhat it means
    Reporting ManagerWho this user reports to
    WarehouseThe distributor/depot the user is mapped to

  5. Set login credentials

    Username (usually the mobile number) and an initial password.

  6. Save, then verify

    The user can now log in with the assigned credentials, confirm they appear in the users list with the correct role, designation and hierarchy mapping.
