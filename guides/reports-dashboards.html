Request a Report or Dashboard

Need a report or dashboard that doesn't exist yet? Send us a filled Functional Specification Document (FSD) with test cases, and our team will scope and build it.

Why an FSD

A Functional Specification Document gives our team the exact shape of what you need (the columns, filters, logic and layout) instead of a back-and-forth over email. Filling it in upfront means your report or dashboard gets built right the first time.

Submitting a request

Download whichever template matches what you need, fill it in, and send it back with test cases attached.

Report FSD Template.XLSX · Column logic & definitions Dashboard FSD Sample.XLSX · Layout & widget reference

  1. Pick the right template

    Report FSD for a new report, Dashboard FSD for a new dashboard view.

  2. Fill in the column logic (or layout, for dashboards)

    Be specific about filters, groupings, and any calculated fields, this is what our team builds directly from.

  3. Write test cases

    A few concrete examples of expected output help us verify the build matches what you actually need before handing it back.

  4. Send it to support

    Email the filled FSD and test cases to support@mobisytechnologies.zohodesk.in.

TipThe more specific the column logic and test cases, the fewer review cycles it takes to get the report signed off.
