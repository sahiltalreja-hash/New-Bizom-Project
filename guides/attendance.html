Attendance & Shift Timing

Attendance timing is controlled through Shift Timings configuration, and you can set it differently per role or designation.

3 min read
Web
Admin access needed
On this page
  1. What you can configure
  2. Steps to change attendance timing

What you can configure

SettingWhat it controls
Shift Start TimeThe time from which attendance (login) is valid
Shift End TimeThe time until which attendance (logout) is valid
Login WindowEarliest time a user can mark attendance
Logout WindowLatest time a user can mark logout
Weekly OffDays marked as non-working

Steps to change attendance timing

  1. Go to the Admin Panel

    Navigate to Admin → Settings → Attendance Settings on the Bizom web portal.

  2. Select the shift

    Find the existing shift assigned to the role/designation you want to update.

  3. Edit the timing

    Click Edit and update the login start/end window and the shift start and end time.

  4. Save

    Click Save to apply the changes.

  5. Verify

    Confirm the updated timings reflect correctly for the assigned roles, designations and users.

TipShift timings can be configured differently per role or designation, so Salesmen and Managers can run on entirely different schedules.
