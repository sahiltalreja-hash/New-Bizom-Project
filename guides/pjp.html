PJP (Permanent Journey Planning)

A Permanent Journey Plan is a pre-defined schedule of which outlets a salesman visits on which days, the backbone of structured, consistent outlet coverage.

4 min read
Web & MDM
Admin access needed
On this page
  1. Create a new PJP
  2. Bulk upload via MDM

Before you startThe salesman must already exist as a user, their beats must be created, and outlets must be mapped to those beats. See Beat Creation & Assigning if you haven't done this yet.

Steps to create a new PJP

  1. Open the user's PJP page

    Go to yourcompanyurl.bizom.in/pjps/pjpupdate/User ID, replacing User ID with the id of the user you're setting this up for, then add the beats you've already created against the days they apply.

  2. Select the user

    FieldWhat it meansRequired
    UserThe salesman/field user this PJP is for✅ Yes
    Effective FromStart date of the PJP✅ Yes

  3. Define the schedule

    Assign beats to specific days of the week or month.

    FieldWhat it meansRequired
    DayMonday / Tuesday / Wednesday, etc.✅ Yes
    BeatThe beat assigned for that day✅ Yes
    Visit FrequencyWeekly / Fortnightly / Monthly✅ Yes

Bulk upload via MDM

Setting up PJPs for a whole team? Use the PJP MDM instead of creating them one at a time.

1Download the MDM template for PJP
2Fill in user, beat, day, and frequency details
