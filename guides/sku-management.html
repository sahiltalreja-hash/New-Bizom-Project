SKU Upload & Update

Create new SKUs one at a time or in bulk, keep existing ones up to date, and manage warehouse-specific pricing separately from the core product record.

4 min read
Web & MDM
Admin access needed
On this page
  1. Add a new SKU
  2. Bulk upload SKUs via MDM
  3. Update / edit an existing SKU
  4. Update SKU pricing
  5. View / search existing SKUs

1. Add a new SKU (single entry)

You can create one SKU at a time from the Add SKU screen at /skunits/add.

What you'll need

GroupFields
Basic InfoSKU Name, SKU Code
ClassificationCategory, Sub-category, Brand, Sub-brand
VariantsSize, Packaging, Sub-pack, Serve Size
PricingMRP, Landing Price (LP), GST %
UnitsUnits per Case, Units per Inner Case

Before you add oneSearch existing SKUs first (see below) to avoid creating duplicates.

2. Bulk upload SKUs via MDM (recommended for large volumes)

Onboarding your full catalogue? Use the SKU MDM instead of adding SKUs one by one.

  1. Navigate to MDMs → SKunits MDM upload

    Found under the MDMs section of the Bizom portal, at yourcompanyurl.bizom.in/skunits/add.

  2. Download the template file

  3. Fill in SKU details

    Name, code, category, brand, MRP, GST, and the rest of the fields listed above.

  4. Upload the filled file back

SKU Units MDM Template.XLS · Ready to fill and upload

NoteAlways use the downloaded template, custom formats may cause upload failures.

3. Update / edit an existing SKU

To update a SKU's name, category, brand, status or other details:

  1. Search for the SKU by name or code

  2. Open the record and edit the required fields

  3. Save changes

Updating many SKUs at once? Use the Skunits MDM update template the same way as the bulk upload above.

4. Update SKU pricing

MRP, Landing Price (LP), Min LP, Max LP and the Focus SKU flag are managed separately from the core SKU record, per warehouse, under SKU Pricing, since the same SKU can be priced differently at each warehouse or distributor.

5. View / search existing SKUs

Before adding a new SKU, search existing ones to avoid duplicates:

  1. Go to Product Master (/skunits)

  2. Use the search/filter to find a SKU by name or code
