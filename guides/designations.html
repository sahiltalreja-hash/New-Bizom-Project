Designations

Designations are the job titles your field hierarchy runs on — TSI, ASM, RSM, ZSM — and every user needs one. Here's how to add new ones.

2 min read
Web
Admin access needed

How to add new designations

  1. Go to Designations

    Navigate to the Admin Panel → /Designations section on the Bizom web portal.

  2. Click "Add Designation"

    Look for the + Add or Create Designation button at the top right of the list.

  3. Fill in the details

    FieldWhat it meansRequired
    Designation NameThe job title/position, e.g. TSI, ASM, RSM, ZSM✅ Yes
    RoleMaps to a system role, e.g. Salesman, Zone ManagerOptional
    ERP CodeExternal ERP ID for integrationOptional
    Active StatusActive or InactiveDefaults to Active

  4. Save

    Click Save or Submit to create the designation.

  5. Verify

    The new designation appears in the list — confirm the name, mapped role, and active status are correct.

NoteDuplicate designation names aren't allowed — if one with the same name already exists, creation will be blocked.

TipYou can add multiple designations one after another by repeating the steps above. Need to create a lot of them at once? Reach out to support with the full list.
