Outlet Categories

Classify outlets by business type (Grocery, Pharmacy, Hotel, Modern Trade and more) so you can filter, report on, and target schemes at the right kind of outlet.

3 min read
Web & MDM

1. What is an outlet category?

An outlet category classifies outlets by business type, Grocery, Pharmacy, Hotel, Modern Trade, and so on. It's used to filter and report on outlets, and to target schemes, MSLs and discounts at the right segment.

Before you startYou'll need admin access, the category names you want to add, and to know which business type each belongs to.

2. Add an outlet category

  1. Go to Admin Panel → Settings → Outlet Categories

  2. Click Add

    Use the + Add / Create button at the top right of the list.

  3. Fill in the details

    FieldWhat to enterRequired
    Category Namee.g. Grocery, Pharmacy✅ Yes
    Category CodeShort code or ERP ID for the categoryOptional
    Business TypeThe business type this category belongs toOptional
    Active StatusActive or Inactive✅ Yes, defaults to Active

  4. Save, then verify

    Click Save, the category becomes available immediately when adding or editing outlets. Go back to the list to confirm it appears with the right details.

3. Bulk upload via MDM

Adding several categories at once? Use the MDM upload instead.

#Step
1Download the MDM template for Outlet Types, MDM name: Outletcategories
2Fill in all category details in the template
3Upload the file via Admin → MDM Upload
4Verify the upload status and fix any errors

TipName categories clearly and consistently, they're used to filter outlets when assigning schemes, MSLs, discounts and activity forms.

WarningOnce a category is assigned to outlets, deactivating it may affect reporting and filtering for those outlets.
