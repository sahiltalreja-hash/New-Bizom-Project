Distributor & Warehouse Creation

Set up the warehouses and distributors that sit at the top of your distribution network, one at a time from the web, or in bulk via MDM.

5 min read
Web & MDM
Admin access needed
On this page
  1. Add a distributor/warehouse via web
  2. Add in bulk via MDM
  3. Updating via MDM

1. Add a distributor or warehouse via the web

For a single new distributor (DB) or warehouse (WH), the fastest path is the company dashboard.

  1. Go to your company dashboard

    Navigate to yourcompanyurl.bizom.in/companies/dashboard

  2. Click any zone, then "Add Distributor or Warehouse"

  3. Fill in the basic fields

    Name, address, contact details, zone and warehouse type are enough to get started, the rest can be filled in later.

2. Add distributors/warehouses in bulk via MDM

Onboarding a whole distribution network at once? Use the Warehouse MDM upload instead of the web form.

  1. Go to yourcompanyurl.bizom.in/mdms

  2. Search for the Warehouse/Distributor upload template and download it

  3. Fill in the required fields and upload

Key fields for the Warehouse MDM
FieldNotes

phonenoMust be a valid phone number.
emailMax 300 characters, must be a valid email.
is_distributor1 if this record is a distributor, 0 if it's a company warehouse. Defaults to 0.
gstinnoMust be a valid GST number.
pannoMax 11 characters, valid PAN format.
license_noOutlet/trade licence number, max 50 characters.
warehousetype_idMust exist in the warehouse types table.
warehousecategory_idMust exist in the warehouse category table and be active.

This is the practical subset, the full template includes 80+ optional columns for finance integrations (QuickBooks, Paytm), invoice numbering sequences and NOC tracking, most of which can be left blank.

TipCreate the zone/subzone first, then the warehouse, the MDM will reject a zone_id or subzone_id that doesn't exist yet.

3. Updating a warehouse via MDM

The Warehouse Update MDM works the same way as the outlet update flow, include the record's id and only the columns you want to change.

  1. Search "update warehouse" under MDMs

  2. Download the template, it only accepts XLS

  3. Fill the id plus the fields you're changing, then upload

NoteA handful of columns (billing/retail sequence numbers, discount categories) show "no support" in the template, whatever you enter is stored, but there's no UI screen that reads it back yet. Leave these blank unless support has asked you to fill them.
