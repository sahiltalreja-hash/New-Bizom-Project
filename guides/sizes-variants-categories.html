Sizes, Variants, Categories & Sub-Categories

The four building blocks behind every SKU, how it's sized, which version it is, and how it's grouped for ordering, reporting and merchandising.

3 min read
Web & MDM
Admin access needed
On this page
  1. Sizes
  2. Variants
  3. Categories & sub-categories

1. Sizes

A Size is a product master attribute used to define the size, volume or weight variant of a SKU, such as 500ml, 1L, 2L, 250g or 1kg.

Create new sizes at /sizes, or upload them in bulk via the Sizes MDM.

2. Variants

A SKU Variant is a different version of the same product, differing by flavour, fragrance, colour or edition, for example.

Add variants at /variants, or upload them in bulk via the Variants MDM.

3. Categories & sub-categories

A Category classifies SKUs into product groups, Beverages, Snacks, Dairy, Personal Care, and so on. It's used for organising products for ordering, reporting and merchandising.

Add categories at /categories, or via the Categories MDM, sub-categories work the same way.

TipSet these up before uploading SKUs, the SKU MDM expects categories, sub-categories, sizes and variants to already exist.
